# 🏯 HUYỄN LINH TÔNG

**HUYỄN LINH TÔNG** – Ứng dụng quản lý và kết nối thành viên của Huyền Linh Tông.

---

## 📖 Giới thiệu

HUYỄN LINH TÔNG là dự án phần mềm được xây dựng bằng Java Swing, hướng đến việc quản lý thông tin thành viên, tài khoản và các hoạt động trong tông môn.

Ứng dụng được thiết kế với giao diện trực quan, dễ sử dụng và hỗ trợ kết nối cơ sở dữ liệu SQL Server.

## ✨ Chức năng chính

- 🔐 Đăng nhập tài khoản.
- 👤 Quản lý thông tin thành viên.
- 🏯 Quản lý Cửu Phong.
- 📋 Quản lý tài khoản.
- 🎮 Các trò chơi mini game.
- 🗄️ Kết nối và quản lý dữ liệu thông qua SQL Server.

## 🛠️ Công nghệ sử dụng

- **Ngôn ngữ:** Java
- **Giao diện:** Java Swing
- **Cơ sở dữ liệu:** Microsoft SQL Server
- **IDE:** Eclipse
- **Đóng gói:** Java JPackage

## 📥 Cài đặt và sử dụng

### Cách 1: Chạy phiên bản đóng gói

1. Tải mã nguồn hoặc phiên bản ứng dụng từ GitHub.
2. Truy cập thư mục:

   `output/HUYEN_LINH_TONG/`

3. Tìm và chạy file:

   `HUYEN_LINH_TONG.exe`

4. Chờ ứng dụng khởi động.

**Lưu ý:** Phiên bản đóng gói có thư mục Runtime đi kèm, không cần cài đặt Java riêng nếu Runtime đã được đóng gói đầy đủ.

### Cách 2: Chạy từ mã nguồn

1. Tải mã nguồn dự án.
2. Mở dự án bằng Eclipse.
3. Cấu hình kết nối SQL Server.
4. Chạy lớp khởi động của chương trình.

## 💾 Cơ sở dữ liệu

Ứng dụng sử dụng Microsoft SQL Server để lưu trữ thông tin.

Người sử dụng cần cấu hình kết nối cơ sở dữ liệu phù hợp với môi trường máy tính của mình trước khi sử dụng các chức năng cần dữ liệu.
